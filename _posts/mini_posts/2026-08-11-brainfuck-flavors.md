Brainfuck, хоть и весьма минималистичный (8 односимвольных команд), [изначально задумывался](https://muppetlabs.com/~breadbox/bf/) как язык, для которого можно сделать минимальный компилятор (уже вторая версия была 240 байт, а на современном железе [можно уложиться в 100](https://github.com/peterferrie/brainfuck/blob/master/brainfuck_nc.asm)).

Если же минимизировать количество команд — то легко уложиться в 2 простые команды (можете поиграться [тут](/counter-machine/)), или в [одну посложнее](/2025/12/30/counter-machine.html).

А если минимизировать количество различных символов? Если отбросить эзотерику, одним из первых тут стал [JSFuck](https://jsfuck.com/), который выразил весь JS через 6 символов: `+!()[]`. А потом код-гольфисты [продолжили](https://codegolf.stackexchange.com/questions/110648/fewest-distinct-characters-for-turing-completeness):
- JS дожали до 5 символов — `` []+=` ``. Как и в JSFuck — приколы типизации.
- Ожидаемо нашлись варианты для Python (`exc="%\n`) и Perl (`<>^es`), но там скучный `exec`/`eval`.
- Внезапно для Haskell надо всего 4 символа — `()=;`, разумеется, не обошлось без [λ-исчисления](/2021/12/16/lambda-calculus.html), точнее, [SKI](https://en.wikipedia.org/wiki/SKI_combinator_calculus).
- Для Си есть решение за 5 символов — `+1;=$`, в котором напрямую прописываются машинные коды.
- В java унылые `02367?\abcdeitu`, по сути просто обычный исходник, написанный через юникод-последовательности `\u0a23`, с гимнастикой для снижения количества нужных цифр.
- В bash — аналогичный подход с `01456\$ '`, zsh чуть интереснее с `$#< (){}`.
- В PHP — 5 символов, `(^.9)`, подходы похожи с JS: делаем числа, из них буквы, потом имена функций и т.д..

Если вернуться к эзотерике, то стоит упомянуть [Whitespace](https://en.wikipedia.org/wiki/Whitespace_(programming_language)), где нужны только `\t \n`. Но победителем будет бесспорно [Unary](https://esolangs.org/wiki/Unary) с прикольной идеей: берем код на Brainfuck, преобразуем его (биективно) в число, пишем соответствующее количество нулей (или любых других символов), и программа готова.
